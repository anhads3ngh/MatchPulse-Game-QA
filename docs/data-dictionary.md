# MatchPulse data dictionary

All schema records are fictional and generated by `engine.init()`.

| Table | Fields | Meaning |
| --- | --- | --- |
| `sessions` | `at`, `platform`, `feature`, `mode`, `build`, `fps`, `latency_ms`, `crashed`, `desync` | Synthetic gameplay observation; `crashed` and `desync` are simulated binary flags |
| `issues` | `title`, `description`, `feature`, `platform`, `severity`, `status`, `owner`, `created_at`, `occurrences`, `repro`, `expected`, `actual`, `build` | Fictional bug report plus reproduction context |
| `qa_runs` | `created_at`, `suite`, `platform`, `seed`, `passed`, `failed`, `duration_ms`, `source` | Reproducible simulated suite execution |
| `test_results` | `run_id`, `name`, `feature`, `outcome`, `duration_ms`, `note` | Individual simulated assertion record |
| `audit` | `issue_id`, `at`, `action`, `before`, `after` | Update history for status, owner and severity |

The example reference date is 2027-04-28 UTC. This is a static fixture time, not a claim about actual QA data in 2027.

### Metric formulas

- **Crash rate** = 100 × crashed sessions / total sessions.
- **Average FPS** = sum of session FPS / total sessions.
- **Feature crash rate** = 100 × crashed sessions in feature / sessions in feature.
- **Stability index (demo-only)** = clipped(100 − crash_rate × 7 − desync_fraction × 65).
- **Severity backlog** = open (`status != Resolved`) Blocker and Critical issues.
- **Test pass rate** = 100 × passed / (passed + failed) for latest local synthetic QA run.
- **Anomaly heuristic** = most recent 3-day crash rate exceeds previous 7-day rate by at least 35% relative and 0.4 percentage points absolute.

This metric system is not validated against any production game or publisher release thresholds.
